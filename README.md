# Acorn A4 'USB' interface (FATFS memory sticks only)

October 2026


![3D View](Generated/3D_View.png)

A work in progress hardware design for the Acorn A4 laptop, providing a USB memory stick (not generic USB) interface using the CH376.

Not yet built or tested!
